# StoreShot Studio

A premium, interactive landing page for **StoreShot Studio** — a concept tool for creating polished App Store and Google Play screenshots.

The website presents the product through a dark, iOS-inspired liquid-glass interface, interactive editor controls, animated product storytelling, and responsive marketing sections.

## Highlights

- iOS-style floating glass navigation with an animated compact scroll state
- Responsive landing page built with plain HTML, CSS, and JavaScript
- Interactive StoreShot editor preview:
  - Selectable layers
  - Editable screenshot headline
  - Background colour controls
  - iPhone / Android canvas switching
  - Modern / classic device frames
  - Drag-to-position device preview
  - Zoom controls
  - SVG screenshot export
- Interactive feature cards:
  - Device preview switching
  - Colour swatch selection
  - Export-size selection
  - Temporary selection states that clear when users click away
- Animated workflow section with floating device, moving cards, and dual rotating orbit rings
- Glass-styled showcase cards and a minimal responsive footer
- Reduced-motion support for visitors who prefer less animation

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Plus Jakarta Sans and Inter

No build tools, frameworks, or package installation are required.

    └── README.md

## Main Interactions

| Area | Interaction |
| --- | --- |
| Navigation | Floating glass bar that becomes compact on scroll |
| Editor preview | Change platform/frame/background, edit title, move device, zoom, and export |
| Feature cards | Select colour/design and export-size controls |
| Workflow | Animated device, staggered workflow cards, and rotating orbit rings |
| Showcase | Glass hover lift and device motion |

## Browser Support

StoreShot Studio is designed for current versions of Chrome, Edge, Safari, and Firefox. The best visual result is available in browsers that support backdrop-filter.
